Secure context required. This page needs to be served over HTTPS or localhost. Run a local server:
python3 -m http.server 8080
How to set up a Spotify Developer App
1 Go to developer.spotify.com/dashboard and log in with your Spotify account.
2 Click "Create app". Fill in a name and description. Set Redirect URI to the URL shown above. Web API is the only type needed.
3 After creating, copy the Client ID from the app settings and paste it above.
4 If using this as a local file, serve it with python3 -m http.server 8080 and open http://localhost:8080/THIS_FILE.html
